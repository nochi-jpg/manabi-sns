4-2. 苦労したこと・直したこと（テーマ別）

Canva サイト（どれも Canva を通さずに開くと起きない）

画面の下が切れる子どもの端末で メッセージ欄などが はみ出す → Canva は ゲームを「横幅×16:9」の高さの枠（iframe）に入れる。枠がブラウザの表示範囲より縦に長い → IntersectionObserver で「実際に見えている範囲」を取って、そこに画面を合わせる タイトルの背景
だけ出ないロゴは出るのに 背景だけ出ない。ゲーム中の背景は出る → 原因は はっきりしないまま。① 再描画させる → きかない ② ステージに画像要素として置く → きかない ③ 先生の「最背面のレイヤーに」案で、ロゴと同じパネルの中の いちばんうしろに画像を置く → 出た 最初の1画面開いた直後の画面だけ 背景が出ない → クッション画面を1枚はさむ。最初は別の層を重ねたら「PUSH START」が残って 押せなくなった → パネルの中身を入れかえる形にして解決 全画面枠の中では 全画面にできないことがある → ボタンを置き、失敗したら「F11をおしてね」 フォント・版使う文字だけのフォントを埋めこむ。タイトルのすみに 1ファイル版を作った日時を出して、差しかえが反映されたか ひと目でわかるように

問題

正解が2つある「上手」に かみて、「降」に こう と答えて不正解 → 漢字の読みを単独で聞いていた → 「雨が降る」のように 文の中で聞く 全問の点検1184問を見直して 約170問を修正（同じ値の別表記が誤答になっている・ふざけた誤答・正解だけ長い・重複 など）。下書きと点検は 分担して進めた 算数・社会4年の問題に x → □。統計の順位に 年を明記

遊ぶ時間と回数

見積もりちがいClaude が「1回20〜30分」と答えていた → 先生が遊ぶと ノーマル3分 → 1日1回の予定を 1日3回に。コンティニューすると 1回分を使う 中断セーブのずる問題の途中で閉じて開きなおすと 別の問題になる → 出ていた問題を保存して、開きなおしても 同じ問題・同じ答えで 出しなおす。ルリの店の品ぞろえも保存。水曜イベントの途中で閉じたら そのイベントは とばす

数字の表示

聖域の残りターン数字が出ない → HPバーのうしろに かくれていた → 位置を直した 9999 の上限法衣なしだと 9999 で止まり、あとで法衣を取っても 増えない → 超えた分を 内部でためて、法衣を手に入れたときに まとめて反映

4-3. 先生の口ぐせ・こだわり

  • 注文は 表と数字で来る（出現率の表、アイテムの効果とデメリット、パスワードの覚え方まで）
  • キャラは 性格をひとことで：「高潔で悪そうな感じ」「無口な感じ」「陽気な感じで」
  • 見た目のそろい：「全角スペースを入れ、絵文字とアイテム名の文字がそろうように」
  • 演出：「パって」ではなく「ジワ〜っと」、撃破は「明滅してから崩れ落ちて」
  • 大きな変更の前は「まだプログラムには触らず、アイデアや意見をください」
  • うまくいかないときも「いいんだけどね」「いいんだけどさ」。直ると「ビンゴ！」
  • 遊びすぎ・ずるへの気くばり：「非常に高い中毒性とリプレイ性で…配布するのをためらって」→ 回数制限・時間制限・コンティニューの代償
  • 次の作品のことを先に考える：「このバグ？のことを、まなバトのほうにも引き継げるようにしといて」
